# psychimgui binding allowlist (SPEC.md sections 5.2, 5.4, 7.2).
#
# One entry per line:
#
#     <ov_cimguiname> [<MatlabName>] [-<arg_name> ...]
#
# The MATLAB name defaults to the "funcname" field of the cimgui definition.
# A -<arg_name> token drops that argument from the MATLAB signature and passes
# its C default instead. Use it only for arguments that carry no useful meaning
# on the MATLAB side, such as a pointer into another argument.
#
# Arguments whose type has no marshaling rule are dropped automatically when
# they have a default (callbacks, user_data, ImGuiStyle* dst). An argument with
# no rule and no default makes the generator refuse the entry.
#
# Sections are namespaces. [ImGui] subcommands have no prefix. [ImPlot] and
# [ImPlot3D] subcommands are called as PsychImGui('ImPlot.Name', ...) and
# PsychImGui('ImPlot3D.Name', ...), and [DrawList] subcommands, the
# ImDrawList methods, as PsychImGui('DrawList.Name', h, ...), where h is a
# handle from GetWindowDrawList and friends.
